# 60–90 second walkthrough script

Legacy n8n walkthrough only. For the hardened local path, demonstrate the current README's accuracy harness, field review queue and audit trail; distinguish the local baseline from Gemini and synthetic data from real-document results. Narrate only what is on screen. Do not claim a client.

1. Open the intake page. Say this is a self-initiated demo, not a client case study.
2. Submit the complete fictional brief. Show COMPLETE, extracted fields, Sheets row, follow-up draft with approval PENDING.
3. Submit the missing-information brief. Show MISSING_INFORMATION and the draft asking for the missing fields.
4. Submit an invalid file or the conflicting brief. Show VALIDATION_ERROR or MANUAL_REVIEW. Say no message is sent until a person approves.

Keep the Drive/public link on Viewer, same rule as the Aarambh walkthrough.
