# Portfolio description (honest)

Self-initiated service demonstration. Not a paid client engagement. No conversion, savings, or revenue claims.

**What it is:** a new-client intake form plus one PDF or image. Spring Boot validates the submission, n8n extracts structured fields with AI, a review status is written to Google Sheets, and any missing-document follow-up is drafted for a person to approve. Nothing is sent automatically.

**What it is for:** overflow n8n / workflow delivery for agencies that already sell automation and need the implementation layer done under their brand.

**Status as of 2026-08-23:** local code, unit tests, workflow export, and three fictional fixtures exist. Live n8n + Sheets path, screenshots, and the 60–90 second walkthrough are the remaining done-criteria.
