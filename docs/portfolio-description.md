# Portfolio description (honest)

Self-initiated service demonstration. Not a paid client engagement. No conversion, savings, or revenue claims.

**What it is:** a new-client intake form plus one PDF or image. The standalone Spring Boot hardening path processes multiple pages and service tables, falls back to local OCR, validates individual fields, and retains a durable audit and review queue. Gemini structured extraction is selectable; the default local rules baseline needs no credentials. Google Sheets delivery is a separate, disabled-by-default outbox using fixed rows. Nothing sends a message automatically.

**What it is for:** overflow n8n / workflow delivery for agencies that already sell automation and need the implementation layer done under their brand.

**Evidence boundary:** the earlier n8n demo and its proof assets are retained. The new hardening path has local automated tests, actual OCR tests and an HTTP accuracy harness. Synthetic results are not real-client accuracy; separate demo credentials and independently labelled real intake forms are still needed for a live AI/Sheets benchmark. Run instructions and operational limits are in `README.md` and `extraction.md`.
